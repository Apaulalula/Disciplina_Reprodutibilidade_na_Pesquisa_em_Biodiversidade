Atividade — Elaboração de um pré-registro

Objetivo: Elaborar o pré-registro de um projeto de pesquisa, com nível de detalhamento mínimo para a reprodução da pesquisa.

Instruções: A atividade deverá ser realizada em grupos. Cada grupo deverá selecionar o projeto de pesquisa de um de seus integrantes e utilizá-lo como base para elaborar o pré-registro. As respostas devem ser objetivas, mas suficientemente detalhadas para descrever os tópicos pertinentes. Caso alguma informação ainda não esteja definida, o grupo deverá propor uma solução viável e justificá-la.

Formato de entrega: Google Docs (lembre-se de deixar aberto para comentários) via e-mail (matheusmaciel.salles@gmail.com, anapaulalula@gmail.com) ou, caso prefira registrar o projeto diretamente no site (osf, as.predicted), enviar o pdf do registro.

1. Metadados do pré-registro

Título do pré-registro

Defina um título sucinto e informativo para o pré-registro, que retrate o foco principal da investigação. Uma denominação clara e precisa facilitará a compreensão imediata do propósito do seu estudo por terceiros.

Descrição

Elabore uma síntese detalhada a respeito do projeto de pesquisa, explicitando seus propósitos centrais e os resultados almejados. Essa contextualização deve proporcionar aos leitores uma visão abrangente e clara sobre o desenvolvimento do estudo.
